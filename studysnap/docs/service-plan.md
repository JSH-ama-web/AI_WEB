# StudySnap 서비스 기획서

## 1. 서비스 개요
- **서비스명:** StudySnap
- **한 줄 소개:** 강의 노트를 붙여 넣으면 AI가 요약 · 핵심 키워드 · 확인 문제를 만들어 주는 복습 도우미
- **배포 URL:** (배포 후 입력)

## 2. 서비스 목적
- 길고 정리되지 않은 강의 노트를 짧은 시간 안에 복습 가능한 형태로 바꾼다.
- 단순 요약에 그치지 않고 **확인 문제**를 함께 제공해 "읽기"가 아닌 "인출 연습" 복습을 돕는다.

## 3. 타겟 사용자
| 구분 | 내용 |
|---|---|
| 주 사용자 | 시험 기간 여러 과목을 동시에 복습해야 하는 대학생 |
| 보조 사용자 | 수업 직후 짧은 복습 습관을 만들려는 학생, 문제를 함께 풀 스터디 그룹 |
| 사용 상황 | 필기 앱/강의자료에서 텍스트를 복사해 PC·스마트폰에서 바로 사용 |

## 4. 페이지 구성 및 메뉴 이동
| 페이지 | 파일 | 주요 내용 |
|---|---|---|
| 홈 | `index.html` | 서비스 소개, 기능 3가지 카드, "지금 정리해 보기" 버튼 |
| 노트 정리하기 | `study.html` | 노트 입력 폼, 문제 개수 선택, AI 결과(요약/키워드/문제), 결과 복사 |
| 사용법 · 소개 | `about.html` | 사용 순서, 추천 대상, 주의 사항, 기술 스택 |

- **메뉴 방식:** 모든 페이지 상단 고정 헤더의 네비게이션 링크로 이동, 현재 페이지 강조 표시
- **모바일(640px 이하):** 햄버거 버튼(☰)을 누르면 메뉴가 펼쳐짐
- **반응형 기준:** 데스크톱(>900px) 3열 카드 / 태블릿(641~900px) 2열 / 모바일(≤640px) 1열

## 5. 핵심 기능
1. **AI 노트 정리** (핵심) — 노트 → 요약 + 키워드 + 확인 문제
2. 확인 문제 정답 가리기/펼치기 (셀프 테스트)
3. 결과 복사하기
4. 다크 모드 (보너스: UX 고도화)

## 6. AI 기능 명세
### 입력
| 항목 | 형식 | 조건 |
|---|---|---|
| `text` | 문자열 (강의 노트) | 필수, 공백 제외 30자 이상 6,000자 이하 |
| `quizCount` | 숫자 | 2 / 3 / 5 중 선택 (서버에서 1~5로 제한) |

### 처리
- 프론트 `fetch('/api/study')` → Python 서버리스 함수 → Claude Messages API 호출
- 시스템 프롬프트로 "노트에 없는 내용은 지어내지 않기", "JSON 형식으로만 답하기"를 지시

### 출력
```json
{
  "summary": "3~5문장 요약",
  "keywords": [{ "term": "용어", "desc": "한 줄 설명" }],
  "quiz": [{ "q": "문제", "a": "정답과 해설" }]
}
```
- 모델이 JSON 형식을 지키지 못한 경우: 응답 원문을 요약 칸에 표시 (빈 화면 방지)

### 사용자에게 주는 가치
- 노트 10분 정독 → 1분 안에 핵심 확인
- 확인 문제로 이해 여부를 바로 점검

## 7. 실패 처리 기준
| 구분 | 조건 | 사용자 안내 메시지 | HTTP 코드 |
|---|---|---|---|
| 빈 입력 | 입력 없음 | "강의 노트를 입력해 주세요." | 400 |
| 입력 길이 | 30자 미만 / 6,000자 초과 | "내용이 너무 짧아요/길어요…" | 400 / 413 |
| 요청 과다 | AI API 429 | "요청이 많아요. 잠시 후 다시 시도해 주세요." | 429 |
| 서버 설정 오류 | 키 누락, 인증 실패 | "서버에 API 키가 설정되지 않았습니다." 등 | 500 / 502 |
| AI 서비스 오류 | 기타 4xx/5xx | "AI 서비스 오류가 발생했습니다. (코드 N)" | 502 |
| 지연 | 8초 경과 | "평소보다 오래 걸리고 있어요…" (대기 유지) | - |
| 타임아웃 | 프론트 30초 / 서버 25초 | "응답 시간이 초과됐어요. 노트를 줄여서…" | 504 |
| 네트워크 | fetch 실패 | "네트워크 연결을 확인해 주세요." | - |

## 8. 운영 · 보안 고려
- API 키는 Vercel 환경 변수 `ANTHROPIC_API_KEY`로만 관리 (코드/README/스크린샷 노출 금지)
- 입력 길이 상한, `max_tokens` 제한, 요청 중 버튼 비활성화로 과금/쿼터 낭비 방지
- 입력 노트는 서버에 저장하지 않음
- 키 유출 의심 시: 즉시 폐기 → 재발급 → 환경 변수 교체 → 재배포 → 커밋 이력 정리
